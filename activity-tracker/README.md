# AK9I Daily Activity Tracker

This folder is the running record of day-to-day AK9I management-plan activity.

## Purpose

Use one Markdown file per workday to capture a concise management summary of:
- work completed;
- meetings and conversations;
- decisions made;
- issues, risks, or blockers identified;
- follow-up actions and owners;
- items carried forward to the next workday.

## Organization

Store daily notes by year and month:

```text
activity-tracker/
├── README.md
├── TEMPLATE.md
└── YYYY/
    └── MM/
        └── YYYY-MM-DD.md
```

Example:

```text
activity-tracker/2026/09/2026-09-21.md
```

## Daily note standard

Keep the daily summary concise enough to scan quickly, but specific enough that a later reader can reconstruct what happened and what remains open.

Use `TEMPLATE.md` as the starting format for each daily entry.
