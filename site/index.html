Presentation Controls

Right Arrow / Space
Advance through the main presentation.
Left Arrow
Return to the prior main slide.
Click a recommendation point
Open its linked detail slide.
Esc
Return from detail or close an open panel.
F
Toggle fullscreen.
O
Open the slide overview.
H
Return to the opening recommendation.
Functional work chart
The main org slide shows who owns each functional category and the primary work inside it.
Reporting hierarchy
Use “View reporting hierarchy” on the functional chart to open the separate authority view, then return to the main chart.
Organization chart names
Click a displayed employee or team name to change the local draft assignment. Published defaults remain in the repository.
90-day initiative matrix
Open it from Recommendation 3. Click any check mark for stage-specific implementation detail; click a responsible-party name to change the local draft assignment. The linked coverage register keeps every item in Ron’s source plan visible.
Organization chart titles
Click a role title to open its current job description in a new tab.
Authority lines
On the hierarchy view, solid lines show direct personnel authority. Dotted relationships show coordination, contracted execution, deployment tasking, or transition.
Customer lanes
Student and contract customer lanes use the same seven-stage architecture: Awareness → Consideration → Enrollment/Commitment → Experience/Delivery → Loyalty → Recurring Relationships → Advocacy. Outcomes are managed inside Loyalty rather than as a standalone stage.
